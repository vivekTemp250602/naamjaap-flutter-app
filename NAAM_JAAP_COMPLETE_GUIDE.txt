1. APP OVERVIEW
================================================================================

App Name: Naam Jaap
Version: 5.1.0 (Build 34)
Platform: Android & iOS (Flutter)
Category: Lifestyle / Spirituality
Target Audience: Spiritual practitioners, meditation enthusiasts, devotees

Tagline: "Your personal sacred space for daily chanting"

Description:
Naam Jaap is a spiritual companion app that helps users practice daily mantra 
chanting (Jaap) with a beautiful digital mala (prayer beads). It combines 
traditional spiritual practices with modern gamification to create an engaging 
and meaningful experience.

19. TROUBLESHOOTING
================================================================================

Common Issues:

1. Notifications not working
   - Check app permissions
   - Enable exact alarms (Android 12+)
   - Disable battery optimization
   - Use test notification button

2. Google Sign-In fails
   - Check internet connection
   - Verify SHA-1 fingerprint in Firebase
   - Clear app cache
   - Reinstall app

3. Audio not playing
   - Check device volume
   - Verify mute toggle is off
   - Check audio file permissions
   - Restart app

4. Sync issues
   - Check internet connection
   - Force sync from settings
   - Sign out and sign in again
   - Clear app data (last resort)

5. App crashes
   - Update to latest version
   - Clear cache
   - Reinstall app
   - Report crash with details
